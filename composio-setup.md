# Composio — Free Setup for Project Andromeda

## What This Does
Connects AI agents & tools without paid Copilot

## 🔑 Get Your Free API Key
1. Go to: app.composio.dev
2. Sign up → FREE tier → 100+ runs/day ✅
3. Copy your API key

## 🔐 Add to GitHub Secrets
1. Project-Andromeda → Settings → Secrets & variables → Actions
2. New repository secret:
   - Name: `COMPOSIO_API_KEY`
   - Paste your key → Save ✅

## ✅ Ready
Your agents.yml will auto-pick it up — no extra install needed!

# 🚀 Project Andromeda
Autonomous open-source AI assistant — cross-platform, mobile-first, fully free & self-improving

## ✨ What It Is
- 📱 **Mobile-first** — built for iPhone + iPad, adapts to every screen
- 🤖 **Self-managing** — auto-deploys, auto-updates via GitHub
- 🔌 **Universal API ready** — OpenRouter, Google, open models, no lock-in
- 🎨 **Remy & avatars** — friendly interface you can customise
- 🛡️ **Forever free & open** — MIT licensed, no forced payments
- 🌐 **Web-only** — no heavy downloads, just open & use

## 🔗 Live Site
**laurence1977.github.io/Project-Andromeda**

## 🚀 How It Works
- Edit → commit → **GitHub deploys automatically**
- API keys stored securely in Secrets — never public
- Built with free tools only — GitHub Actions + Pages
